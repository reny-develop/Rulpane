For an AI asked to make a Rulpane link

People see a short guide on the page; this part is for an AI reading the page as text.

Rulpane (https://reny-develop.github.io/Rulpane/) opens a working screen from one link. The link carries a paneset: one JSON document holding

  • "$schema": "rulpane/paneset/v1" — required;
  • r, the rules: a Rulealize rule set, written in place — required;
  • v, the view: what the screen shows and where, with "$schema": "rulealize/view/v1" — optional; without it the screen is made from the rules;
  • t, the theme, with "$schema": "rulealize/theme/v1" — optional;
  • s, the state's data to start from — optional; the rules' own state.initial without it;
  • b, which of the rules' names the view reads under other names — optional.

What to do

  1. Work out what can be done in the system, by whom, and when it is finished.
  2. Start from a whole example and change it. Each start-page sample is a rule set and a view that open as they are: rules and view of a split bill, and the same for packing-list and scoreboard. Write them into the paneset as r and v.
  3. Look up every operation before using it. The Rulealize Registry has a page for each, such as https://reny-develop.github.io/Rulealize.Registry/op/seq.where.html, which leads to its plugin's specification: that gives every key it takes. How a rule set is laid out is in the quick guide. Use only the plugins listed at the end of this page.
  4. The view's blocks and keys are in Rulpane's README.
  5. Give the person the link: https://reny-develop.github.io/Rulpane/#p= followed by the paneset as JSON on one line, with every space written as %20, inside strings too — a chat cuts a link at the first space. Nothing else needs encoding.
  6. Give the JSON itself too, in a code block, and say: if the link does not open, paste the JSON at https://reny-develop.github.io/Rulpane/#make, press "Make link" and tell me the reason it shows. The reason names the key that is wrong.
  7. When the request needs it, say plainly what a link cannot do: it keeps no secrets, anybody holding it can take any step, and two people working from one link make two separate histories.

Before you answer

  • The paneset, and the view and the theme when written, each have their $schema.
  • Every operation is one a listed plugin has, with only the keys its specification gives.
  • Every plugin whose operation, $, @ or # is used is in requires.
  • Lists where an expression goes are seq.of, not JSON arrays (arrays are fine in state.initial, s and a view).
  • No open parameter is read in when, actor or a domain; every validate clause reads one.
  • Every view binding names a projection the rules have, or a state field as $name.
  • The link is one line, and every space in it is %20.

How to write one

A paneset also opens written on one line after #p= in the link.

https://reny-develop.github.io/Rulpane/#p={"$schema":"rulpane/paneset/v1","r":{…},"v":{…}}

If you write a link by hand and send it in a chat, write each space as %20 so the chat does not cut it short; a link made with “Make a link from JSON” has no spaces. A link that does not open says why: paste it into Make a link from JSON above to put it right.

  • Rulealize.Registry

    Find the operations rules can use, by name. Each plugin's page leads to its specification, which gives every key.

    r

  • Rulpane.Gallery

    Find views, themes and panesets. Look up a rule set by name to see the views that fit it as they are.

    v t p

The formats in full: rule sets in Rulealize's quick guide; views, themes and the plugins Rulpane runs in Rulpane's README.

A link keeps no secrets: whoever holds it sees everything in it and can take any step.

書き方

ペインセットは、リンクの #p= の後ろに 1 行で書いても開けます。

https://reny-develop.github.io/Rulpane/#p={"$schema":"rulpane/paneset/v1","r":{…},"v":{…}}

リンクを手で書いてチャットで送るなら、空白を %20 にしておくと途中で切れません（「JSON からリンクを作る」で作ったリンクには空白が入りません）。開けないときは理由が出るので、上の「JSON からリンクを作る」に貼って直してください。

  • Rulealize.Registry

    ルールに使える演算を、名前で探せます。キーの書き方は、プラグインのページからたどる仕様書にあります。

    r

  • Rulpane.Gallery

    ビュー・テーマ・ペインセットを探せます。ルールセットの名前から、そのまま合うビューも引けます。

    v t p

書式の詳しい説明は、ルールセットが Rulealize のクイックガイドに、ビュー・テーマ・使えるプラグインが Rulpane の README にあります。

リンクには秘密を持てません。リンクを持つ人は誰でも中身を見られ、どの操作もできます。
