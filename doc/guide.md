## How to write one

A paneset also opens written on one line after `#p=` in the link.

::: card
```text
https://reny-develop.github.io/Rulpane/#p={"$schema":"rulpane/paneset/v1","r":{…},"v":{…}}
```

If you write a link by hand and send it in a chat, write each space as `%20` so the chat does not cut it short; a link made with “Make a link from JSON” has no spaces. A link that does not open says why: paste it into [Make a link from JSON](#make) above to put it right.
:::

- [Rulealize.Registry](https://reny-develop.github.io/Rulealize.Registry/)

  Find the operations rules can use, by name. Each plugin's page leads to its specification, which gives every key.

  `r`

- [Rulpane.Gallery](https://reny-develop.github.io/Rulpane.Gallery/)

  Find views, themes and panesets. Look up a rule set by name to see the views that fit it as they are.

  `v` `t` `p`

The formats in full: rule sets in Rulealize's [quick guide](https://github.com/reny-develop/Rulealize/blob/main/doc/ruleset-quickguide.md); [panesets](https://github.com/reny-develop/Rulpane#panesets), [views](https://github.com/reny-develop/Rulpane#views), [themes](https://github.com/reny-develop/Rulpane#themes) and [the plugins Rulpane runs](https://github.com/reny-develop/Rulpane#plugins) in Rulpane's [README](https://github.com/reny-develop/Rulpane#readme).

A link keeps no secrets: whoever holds it sees everything in it and can take any step.
